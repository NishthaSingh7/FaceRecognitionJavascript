# FaceRecognitionJavascript

## Project name
FaceElevate (Face Recognition Javascript)

## Purpose
A browser-based face analysis demo that estimates emotion, gender, and age from a live webcam feed for e-commerce personalization experiments.

## Features
- Live webcam face detection
- Emotion recognition
- Gender estimation
- Age estimation
- Runs entirely in the browser with face-api.js models

## Tech Stack used
- HTML / CSS / JavaScript
- face-api.js (TensorFlow.js models)
- Web APIs (getUserMedia)
